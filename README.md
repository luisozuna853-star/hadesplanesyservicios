# Hades Photo Studio — sitio web

- `index.html`: la página. Lee las galerías de Supabase.
- `admin.html`: panel para editar galerías (entrar con tu correo y contraseña).
- `supabase_config.js`: URL y clave pública de Supabase, usadas por admin.html.
- `supabase_schema.sql`: tablas y permisos. Se corre una sola vez en el SQL Editor de Supabase.
- `fotos-planes/`: miniaturas que enlazan los mensajes de WhatsApp.
- `fuente/`: archivos con los que se generó el index.

Para publicar: sube a la raíz del repositorio todo el contenido de este proyecto.
