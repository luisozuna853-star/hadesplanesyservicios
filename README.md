# Hades Photo Studio — sitio web

- `index.html` es el sitio completo (un solo archivo). Es lo que se publica.
- `fotos-planes/` tiene una miniatura por categoría; el mensaje de WhatsApp la enlaza. Tiene que subirse junto al index.
- `fuente/` contiene los archivos con los que se generó el index.

Para publicar en Vercel: el `index.html` y la carpeta `fotos-planes/` tienen que estar en la raíz del repositorio.
