# Hades Photo Studio — sitio web

- `index.html`: la página completa (servicios, planes, precios y WhatsApp).
- `fotos-planes/`: miniaturas de los planes para los mensajes de WhatsApp.
- `fuente/`: archivos con los que se generó el index.

Para publicar: sube a la raíz del repositorio index.html y fotos-planes/.
