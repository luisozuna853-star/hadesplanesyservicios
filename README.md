# Hades Photo Studio — sitio web

- `index.html` es el sitio completo (un solo archivo). Es lo que se publica.
- `fuente/` contiene los archivos con los que se generó el index: `build2.py`, `style2.css`, `imgs.css`, `ratios.json`, `plans.json`.

Para publicar en Vercel: el `index.html` tiene que estar en la raíz del repositorio.
